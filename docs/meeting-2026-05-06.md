# Campaign Platform · 项目启动会

## 一句话定位
> 活动页搭建平台 —— 让运营能快速出活动页，开发不用每次重复写页面

## 技术方案
- **后端**：Go（Gin + GORM）— 后端 A / B
- **前端**：Next.js SSR — 后端 B（全栈偏前端）
- **数据库**：PostgreSQL
- **服务器**：阿里云 4C8G（¥371/月）
- **CI/CD**：GitHub Actions → systemd 自动部署

## 项目结构
```
campaign-platform/
├── backend/      Go API（9 个接口）
├── web/          Next.js 渲染引擎
├── migrations/   建表 SQL
├── deploy/       systemd + nginx
└── .github/      CI/CD
```

## MVP 范围（第一个月）
1. **Go API**：活动 CRUD + 版本管理 + render 接口（后端 A）
2. **渲染引擎**：配置读 DB 跑 Next.js SSR（后端 B）
3. **组件**：HeroBanner + CTAButton，2 个够用（后端 B）
4. **端到端**：写配置 → 审核 → 上线 → 用户看到页面
